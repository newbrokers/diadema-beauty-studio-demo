# Diadema Beauty Studio — concept demo

Concept website built for outreach to **Diadema Beauty Studio**, a beauty
studio in Limassol, Cyprus (Chrysanthou Mylona 5). Their Google Business
listing has a 5.0 rating from 32 reviews and only a Taplink link-in-bio —
this is a first-draft concept to show them what a real site could look like.

- Built from the studio's real Google Business photos, rating, address, and phone.
- Services list is a generic placeholder — swap in the real menu before sending.
- `index.html` is fully self-contained (images embedded as base64) — deploy as-is to Vercel, no build step needed.
